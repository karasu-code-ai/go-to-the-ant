# Go to the Ant — the JavaScript edition

Every system here coordinates the same way: through a shared, decaying field — local reads and writes, no
messaging, no global state. That idea is language-agnostic, and each edition is the same faithful, bit-identical
recreation seen through one language's lens — free to grow its own way from a common foundation.

**The JS lens** — it runs in every browser with no install, so its contribution is the *view*: the swarms made
watchable and shareable in a single link. Natural directions lean into that — richer interactive visualizations,
and pushing the simulation itself (WASM / WebGPU) so larger swarms stay smooth on the client.
